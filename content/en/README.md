# English translation — not started

La version anglaise n'est pas commencée.

## Politique de traduction

Conformément au PRD :

- la version française doit être validée avant toute traduction ;
- les textes historiques doivent être relus par une personne compétente ;
- les citations et témoignages doivent conserver leur sens exact ;
- les crédits et mentions de droits doivent être traduits avec précision ;
- les documents d'archives ne doivent pas être reproduits sans autorisation, quelle que soit la langue ;
- les statuts de validation doivent être conservés.

## Structure prévue

Lorsqu'une traduction sera entreprise, créer :

```text
content/en/
├── chapters.json
├── people.json
├── documents.json
├── timeline.json
├── glossary.json
├── narratives.json
└── sources.json
```

Les identifiants doivent rester identiques à la version française pour préserver les références croisées et les sauvegardes.

## Ne pas faire

- Traduire automatiquement sans relecture.
- Inventer une citation pour l'adapter.
- Modifier les dates, les noms ou les parcours.
- Présenter une traduction comme un document historique original.
- Publier une traduction avant validation de la version française.
